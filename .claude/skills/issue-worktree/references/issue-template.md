# 이슈 본문 템플릿

제목: `[유형] 한 줄 설명` (50자 내외, 예: `[기능] 정류장별 환승 비율 분석 추가`)

본문(그대로 `--body-file`로 사용):

```markdown
## 배경
왜 필요한지 1~3문장. 요청에 근거가 없으면 추정한 내용에 "(추정)"을 붙인다.

## 작업 내용
- [ ] 구체적인 작업 1
- [ ] 구체적인 작업 2

## 완료 조건
- [ ] 결과를 확인할 수 있는 기준 1
- [ ] 결과를 확인할 수 있는 기준 2

## 참고
관련 파일·이슈·데이터 (없으면 이 섹션 생략)
```

규칙
- 한국어로 작성한다. 작업 내용은 체크리스트로 쪼개 진행 상황이 이슈에서 보이게 한다.
- 개인정보(카드번호, 이름, 연락처), 키·토큰, 원본 이동 이력 값은 넣지 않는다. 필요하면 "가명처리된 데이터"처럼 일반화한다.
- 공개 저장소일 수 있으므로 내부 시스템 주소·경로도 넣지 않는다.
